# Nad Defense

A simple fun arcade game that was created for the Monad Community by 0xLukkz powered by Monad Games ID

## Demo

You can find a playable demo of the game on here: [Play]()

## How To Play

Currently, the only supported way to play the game is with a Keyboard.

### Controls

| Keys                        | Description                                       |
| --------------------------- | ------------------------------------------------- |
| Arrow Keys (Left and Right) | Rotates the players ship around the Monad Planet. |
| Spacebar                    | Fire main weapon.                                 |
